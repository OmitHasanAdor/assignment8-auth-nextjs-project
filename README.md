# 🛒 SunCart – Summer Essentials Store

[![Live Site](https://img.shields.io/badge/Live%20Site-Visit-blue?style=for-the-badge)](https://assignment8-auth-nextjs-project.vercel.app/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/OmitHasanAdor/assignment8-auth-nextjs-project)

### SunCart is a modern, fully responsive e-commerce web application built for summer essentials shopping. With secure authentication, an attractive user interface, and smooth browsing experience, SunCart makes it easy for users to discover and shop products across mobile, tablet, and desktop devices.

---

## Technologies Used

* **Frontend Framework:** React.js & Next.js
* **Language:** TypeScript
* **Authentication:** Better Auth (with Google Login)
* **Styling & UI Components:** Tailwind CSS, DaisyUI
* **Notifications:** React-Toastify
* **Icons:** React Icons
* **Animations:** Animate.css
* **Product Data:** JSON
* **Deployment:** Vercel

---

## Features

1. **Secure Authentication System:** User sign-up and sign-in powered by Better Auth, keeping accounts safe and sessions secure.
2. **Google Authentication:** One-click Google login/signup for a fast, hassle-free onboarding experience.
3. **Dynamic Routing:** Seamless page navigation and product routing built with Next.js App Router.
4. **Fully Responsive Design:** A clean, adaptive layout that works flawlessly across mobile, tablet, and desktop screens.
5. **Interactive Animations:** Smooth entrance and hover animations using Animate.css for a more engaging shopping experience.
6. **Toast Notifications:** Real-time feedback (success, error, and info alerts) using React-Toastify for actions like adding to cart or login status.
